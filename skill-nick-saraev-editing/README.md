# Skill de edición · Nick Saraev

Edita reels en el estilo de Nick Saraev: lienzo oscuro/claro, título con caja azul, ventana enmarcada con asas tipo Figma que muestra la
herramienta, él en un recuadro redondeado abajo, subtítulo que se enciende palabra a palabra y cierre «comment PALABRA».
Entrenada con los 20 videos de este repositorio (≈340 escenas medidas).

## Instalar
1. Descarga `nick-saraev-editing.zip` (botón **Download raw file**).
2. **Claude:** Ajustes → Capacidades → Skills → *Subir skill*. **Claude Code:** descomprime en `~/.claude/skills/nick-saraev-editing/`.
   **ChatGPT / Gemini:** sube el zip al chat y escribe «Lee EMPIEZA_AQUI.md y sigue SKILL.md».
3. Sube tu clip: «Edita este video con la skill nick-saraev-editing».

## Qué trae
`SKILL.md`, `REGLAS_GENERALES.md`, `docs/` (RULEBOOK, EDIT_LOGIC, FORMATOS, Katana, Edit Studio), `library/` (ejemplos con hoja de fotogramas),
`references/` (desglose por video), `system/` (motor de render, subtítulos, sonido, panel A/B/C, capturas web `evidence.py`), `plugins/edit-studio/`. Ejemplo en `ejemplo/`.
